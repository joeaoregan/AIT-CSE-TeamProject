## Functional Requirements

### [Customer](users.md#customer)

- [x] Customer should be able to search before logging in
- [x] Within the search the customer should have access to rental price- dependent on management
- [x] Available dates- dependent on management and skipper.
- [x] Available boats- dependent on management.
- [x] Customers must register to make a booking- dependent on add, edit below.
- [x] They should be able to add, edit, delete their name.
- [x] They should be able to add, edit, delete their address.
- [x] They should be able to reset their password for their log in.
- [x] They should be able to create a "shopping basket"- dependent on add, edit below.
- [x] They should be able to add to their basket.
- [x] They should be able to delete from their basket.
- [x] Before checkout they should be presented with the option to reserve the skipper for the day- dependent on skipper calendar.

### [Front Desk Staff](users.md#front-desk) 

- [x] Staff should have access to current and pending bookings.
- [x] Be able to add/update new bookings.
- [x] Add customers to the system (Personal details, contact, payment)
- [x] dd check-in/out details to the bookings.

### [Skipper](users.md#skipper)

- [x] Upload his/her profile
- [x] Record days available for skippering
- [x] View days booked
- [x] View boats booked on
- [x] View pickup docking harbour points for days booked
- [x] View destination docking harbour points for days booked
- [x] Update the system when the job is complete

### [Management](users.md#manager)

- [x] Administer employee details
- [x] Create boat inventory
- [x] Maintain boat inventory
- [x] Create equipment inventory
- [x] Maintain equipment inventory
- [x] Create pricing structures
- [x] Maintain pricing structures
- [x] Generate monthly financial reports
- [x] Generate yearly financial reports

---

## Non-Functional Requirements

- [x] Users of the system must be confident in using it after one week of training
- [x] The user interface must be intuitive to navigate
- [x] Unambiguous results messages must be provided
- [x] A consistent layout will be used throughout the website/application
